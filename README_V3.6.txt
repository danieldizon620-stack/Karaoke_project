dannyboi's Karaoke v3.6 - Windows Program Files Installer Build

Build on Windows using GitHub Actions > Build Windows Installer EXE.
The generated installer requests administrator privileges and installs under Program Files.
It creates a desktop shortcut (optional) and Start Menu entry.
To pin: launch the app, right-click its taskbar icon and select Pin to taskbar.

YouTube playback: uses official privacy-enhanced youtube-nocookie.com embed.
Video-owner restrictions (errors 101/150 or other embedding blocks) CANNOT be bypassed.
Use the Open on YouTube button when embedding is blocked.
A YouTube Data API v3 key is required for search, but not for adding a direct video link.

Note: this ZIP contains source and an installer build workflow, NOT a compiled installer EXE.
